# DACH-CSS 2027: historical Qwen prompt comparison

Research-in-progress materials for **On Topic, but Unanswered? Measuring Political Responsiveness in Brazilian Portuguese with Human and LLM Annotations**.

This directory extends the repository's multi-annotator study. It is separate from the earlier 276-item benchmark and does not replace that benchmark's results or scripts.

## Start here: reproduce the stored results

From the root of `roda-viva-evasion`, run:

```bash
python experiments/dach_css_2027/scripts/evaluate.py
```

Python 3.10+ is sufficient. This command uses the included **labels-only snapshot**, does not call Groq, and requires no API key or package installation. It writes `metrics.json`, `summary.md`, and `paired_items.csv` under this experiment's `results/` directory. Run the checks with:

```bash
python -m unittest discover -s experiments/dach_css_2027/tests -v
```

For Colab, open `notebooks/02_reproduce_metrics.ipynb`. The notebook only downloads this public repository and recomputes the stored metrics. The folder must first be uploaded to GitHub for the public notebook workflow to find it.

## Scope and interpretation

The snapshot contains 694 question–answer identifiers from 11 interviews. It includes three partially overlapping human annotation columns and the stored predictions of two Qwen annotation pipelines. There are 455 items with complete triple human annotation, with unanimity in 322 of them (70.8%). The paired evaluation includes 248 items with at least two agreeing human votes and valid predictions in both pipelines. The strict sensitivity analysis includes 239 items with all three human annotations.

`RESPONDE` includes direct statements of ignorance or refusal under the existing annotation guide. These labels concern the question–response relationship under that protocol. They do not establish truth, intent, or complete substantive disclosure. Individual human labels remain available; reported model metrics use a provisional majority reference.

**Historical provenance limitation:** the source Colab defines two guided prompts, with and without examples. Its resume cell writes to the same `QWEN_ROTULO` column, without recording a prompt identifier per row. Both exact prompt texts are archived here. The historical guided results cannot be attributed to a single exact variant at row level. Describing these results as a perfectly controlled single-prompt run would be stronger than the available record permits. See [provenance](docs/provenance.md).

The evaluated sample was processed sequentially, not selected by a representative sampling design. The strict subset and exclusion of Aécio are descriptive sensitivity analyses. No elimination of length bias or generalisation to all Brazilian politicians is claimed.

## Future runs with explicit prompt versions

`scripts/run_qwen.py` is a new runner prepared from the original notebook. It records prompt hashes, selected item IDs, model identifier, temperature, SDK version, responses, and usage. It refuses to resume an output directory with a different configuration. It is not the historical script that produced the stored predictions.

Preview a small future run without API calls:

```bash
python experiments/dach_css_2027/scripts/run_qwen.py \
  --input /path/to/private/resultados_anotacao_llms.csv \
  --output experiments/dach_css_2027/private_runs/new_comparison \
  --conditions simple guided_with_examples \
  --items experiments/dach_css_2027/results/paired_items.csv \
  --limit 5
```

The preview prints the selected sample size and maximum request count. To execute deliberately, install the optional dependency and provide `GROQ_API_KEY` through the environment or Colab Secrets, then add `--execute`. The script does not load `.env` files automatically. Do not paste keys into notebook code.

```bash
python -m pip install -r experiments/dach_css_2027/requirements-inference.txt
```

In Colab, the credential setup is:

```python
import os
from google.colab import userdata
os.environ["GROQ_API_KEY"] = userdata.get("GROQ_API_KEY")
```

Use a different output directory for each configuration. `--limit 0` selects all matched input items. Responses and explanations generated by new runs stay in `private_runs/`, which is excluded by this directory's `.gitignore`. Only the question and response fields are sent to the model; human labels are not included in API messages. A provider/format error stops the run and saves progress instead of silently switching models or prompts. Future inference uses quota and may incur charges; no new inference was executed when preparing this package.

The historical model identifier is `qwen/qwen3.8-27b`. Model availability can change. Do not silently substitute another model when claiming historical replication. The runner accepts an explicit `--model` and records it in the manifest.
