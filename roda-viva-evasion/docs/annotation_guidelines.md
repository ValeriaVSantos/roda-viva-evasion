# Annotation guidelines

## Task

Read each journalist question and politician response. Assign the label that best describes whether the response satisfies the **central communicative goal** of the question.

## Labels

### RESPONDE

The response directly addresses the central point. It may omit secondary details or add context, provided that it still answers what the journalist principally asked.

### PARCIAL

The response remains on the same topic but avoids a key aspect, gives an incomplete answer, or introduces a substantial digression that leaves the central point unresolved.

### ESQUIVA

The response changes the topic, answers a different question, or uses a rhetorical move that avoids the central point altogether.

## Decision procedure

1. Identify the central communicative goal of the question. Ignore opening conversation and background that does not change what is being requested.
2. Determine whether the response addresses the same topic. If not, consider `ESQUIVA`.
3. If it addresses the same topic, determine whether it answers the specific point. Use `RESPONDE` when it does and `PARCIAL` when it addresses only part of the request.

## Difficult cases

- **Two-part question:** prioritize the principal, usually more specific, request. Answering only a secondary part generally supports `PARCIAL`.
- **Praise followed by redirection:** use `ESQUIVA` if the central point is never addressed.
- **Vague answer on the same topic:** use `PARCIAL`, not `RESPONDE`, when the specific request remains unanswered.
- **“I do not know” or “I cannot answer”:** treat this as `RESPONDE` when it directly states the speaker's answer to the question.
- **Long response:** length is not evidence of responsiveness. Judge the content in relation to the question.
- **Uncertainty between labels:** record both candidates and the reason in an adjudication note. The original guide proposed the conservative ordering `RESPONDE > PARCIAL > ESQUIVA`; the adjudication report should document any use of this rule.

## Recommended adjudication fields

- item identifier;
- initial labels from A, B, and C;
- disagreement type;
- adjudicated label;
- adjudicator;
- short rationale;
- date and guideline version.

These guidelines are adapted from the Portuguese annotation workbook used in the expanded study.
